פלט מובנה בלי להמר: JSON, סכמות ו-pydantic

🎯 מה תדעו לעשות: לגרום למודל להחזיר נתונים שהקוד שלך יכול לסמוך עליהם — JSON מוגדר סכמה, מאומת ומטופל בשחזורים.
נועה · השמע את המרצה

למה פרומפט בלבד לא מספיק

לבקש 'החזר JSON' בטקסט חופשי עובד רוב הזמן — ורוב הזמן זה לא מספיק לפרודקשן. המודל יכול לעטוף במרכאות, לכתוב הערות, לשכוח שדה או להמציא enum חדש. הכלל: כל מה שהקוד שלך צריך לפרסר חייב להיות מוגדר בחוזה — סכמה. פרומפט מסביר למודל מה נחמד; סכמה אוכפת מה נכון. השילוב המנצח: סכמה מדויקת ב-API וולידציה ב-pydantic בצד שלך, כי שתי שכבות של ביטחון תמיד עדיפות על אחת.

JSON mode מול strict schema

לרוב הספקים יש שתי רמות: json_mode (מבטיח JSON תקין אבל לא צורה) ו-json_schema (strict — הפלט חייב לעמוד בסכמה, כולל additionalProperties: false). תמיד תעדוף strict schema.

`python

client.chat.completions.create(

model='gpt-4o-mini',

messages=[...],

response_format={

'type': 'json_schema',

'json_schema': {

'name': 'meeting',

'strict': True,

'schema': {

'type': 'object',

'properties': {

'date': {'type': 'string'},

'participants': {'type': 'array', 'items': {'type': 'string'}}

},

'required': ['date', 'participants'],

'additionalProperties': False

}

}

}

)

`

pydantic כשכבת אמת

גם עם strict schema, האמת הסופית היא אצלך. pydantic מאמת טיפוסים, טווחים ואילוצים בזמן ריצה — וספריות כמו instructor מחברות אותו ישר ל-API עם לולאת retry אוטומטית.

`python

from pydantic import BaseModel, Field

class Meeting(BaseModel):

date: str

participants: list[str] = Field(default_factory=list)

action_items: list[str]

m = Meeting.model_validate_json(raw)

`

טיפ: תיאורי שדות (descriptions) בסכמה הם חלק מהפרומפט — הם משפיעים על איכות החילוץ לא פחות מההוראות שלך.

מתי להיזהר

שלושה פחים: (1) enums גדולים מדי — המודל יטעה בערכים נדירים, תן דוגמאות; (2) שדות optional רבים — המודל נוטה לא למלא, אם חשוב תעשה required עם ערך ברירת מחדל כמו 'unknown'; (3) nested עמוק מדי — שטח את הסכמה, רשימה של אובייקטים שטוחים עדיפה על עץ בן שלוש קומות. ולולאת שחזור: מקסימום 2–3 ניסיונות, עם הודעת השגיאה מה-validator בתור הודעת המשך — המודל מתקן את עצמו מצוין כשמראים לו מה נשבר.

פרומפט מוכן להעתקה

חילוץ מפגש מסוכם עם סכמה strict: ```python schema = { 'name': 'meeting_summary', 'strict': True, 'schema': { 'type': 'object', 'properties': { 'date': {'type': 'string', 'description': 'YYYY-MM-DD או unknown'}, 'participants': {'type': 'array', 'items': {'type': 'string'}}, 'action_items': {'type': 'array', 'items': {'type': 'string'}} }, 'required': ['date', 'participants', 'action_items'], 'additionalProperties': False } } ```

פרומפט סיוע לחילוץ (לשים לפני הטקסט): ``` חלץ מגזירת הפגישה את התאריך, המשתתפים והחלטות הפעולה. אם מידע חסר — החזר 'unknown' ולא ניחוש. שמות צריכים להיות מלאים כמו שמופיעים בטקסט. ```
