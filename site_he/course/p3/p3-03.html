Function Calling מקצה לקצה

🎯 מה תדעו לעשות: לבנות לולאת כלים תקינה — מהגדרת פונקציה ועד ביצוע, טיפול שגיאות וקריאות מקבילות.
נועה · השמע את המרצה

החוזה: להגדיר כלי נכון

כלי זו פונקציה רגילה בקוד שלך + הגדרת JSON schema שהמודל רואה. התיאור (description) הוא הפרומפט של הכלי — המודל בוחר לפיו מתי לקרוא ומתי לא.

`python

tools = [{

'type': 'function',

'function': {

'name': 'get_weather',

'description': 'מזג אוויר נוכחי לעיר. השתמש רק כשהמשתמש שואל על מזג אוויר ספציפי.',

'parameters': {

'type': 'object',

'properties': {

'city': {'type': 'string'},

'units': {'type': 'string', 'enum': ['c', 'f']}

},

'required': ['city'],

'additionalProperties': False

}

}

}]

`

שמות פעלים מדויקים, enum במקום מחרוזת חופשית, ופרמטר אחד = אחריות אחת.

הלולאה: המקום שבו רוב האנשים נופלים

זו לא קריאה אחת — זו לולאה. המודל מחזיר tool_calls, אתה מריץ, מחזיר את התוצאה עם role: 'tool', וחוזר חלילה עד שהמודל עונה תשובה סופית.

`python

while True:

r = client.chat.completions.create(model=M, messages=msgs, tools=tools)

msg = r.choices[0].message

if not msg.tool_calls:

break

msgs.append(msg)

for tc in msg.tool_calls:

result = dispatch(tc.function.name, json.loads(tc.function.arguments))

msgs.append({'role': 'tool', 'tool_call_id': tc.id, 'content': json.dumps(result)})

`

גבול עליון לאיטרציות (10–15) חובה — סוכן בלי רצפה פוגע בעצמו, ובתקציב שלך.

שגיאות הן חלק מהפרוטוקול

המודל לא מריץ את הקוד — אתה. אם כלי נכשל, אל תזרוק exception למעלה: תחזיר למודל אובייקט שגיאה כמו {'error': 'city not found: did you mean Rehovot?'}. המודל מתמודד עם שגיאות מפורטות מצוין — הוא יתנצל, יתקן פרמטר וינסה שוב. מה שהורג סוכנים זה שגיאות כלליות (something went wrong) שמשאירות אותו עיוור. גם timeout, גם תוצאה ריקה, גם חריגה ממכסה — הכול חוזר למודל כמידע. סוכן טוב לא זה שלא נכשל, זה שמתאושש.

קריאות מקבילות ומגבלות

מודלים מודרניים מחזירים כמה tool_calls בבת אחת — תממש ביצוע מקבילי (asyncio.gather) כשהכלים בלתי תלויים, זה חיסכון של שניות בכל תור. אבל: כלים עם תופעות לוואי (שליחת מייל, חיוב, מחיקה) מריצים בטור או עם אישור משתמש — parallel tool calls ורישום כפול זה סיפור אמיתי שקרה לכולם. חשוב גם לזכור שכל סבב כלים מוסיף טוקנים להודעות והלולאה עלולה להתנפח — תמזער את תוצאות הכלים (למשל 200 השורות הראשונות של קובץ, לא כל הקובץ).

פרומפט מוכן להעתקה

תבנית הגדרת כלי (העתק והתאם): ```python tool = { 'type': 'function', 'function': { 'name': 'search_docs', 'description': 'מחפש בתיעוד הפנימי. השתמש לכל שאלה על מוצר או מדיניות.', 'parameters': { 'type': 'object', 'properties': {'query': {'type': 'string'}, 'top_k': {'type': 'integer', 'default': 5}}, 'required': ['query'], 'additionalProperties': False } } } ```

פרומפט system לסוכן כלים: ``` אתה סוכן תמיכה. לפני כל תשובה, בדוק אם כלי יכול לספק מידע עדכני. אל תמציא נתונים — קרא לכלי. אם כלי נכשל פעמיים, ענה מה שידוע וציין את הכשל. מקסימום 8 קריאות כלים לפני תשובה סופית. ```
