נועה · השמע את המרצה

מה MCP בעצם מסדר

MCP הוא פרוטוקול פתוח שמפריד בין 'מי מספק יכולות' (שרת MCP) ל-'מי צורך אותן' (לקוח — Claude Desktop, IDE, הסוכן שלך). שרת חושף שלושה סוגים: tools (פעולות שהמודל מריץ), resources (נתונים לקריאה — קבצים, שורות DB), prompts (תבניות מוכנות). התעבורה stdio או HTTP, וההודעות JSON-RPC. הערך הגדול: כותבים אינטגרציה ל-GitHub פעם אחת וכל לקוח בעולם יכול להשתמש בה — ולהפך, אתה מקבל אלפי שרתים מוכנים בחינם.

שרת MCP ראשון בעשר דקות

`python

from mcp.server.fastmcp import FastMCP

mcp = FastMCP('currency')

@mcp.tool()

def convert(amount: float, from_: str, to: str) -> str:

'''ממיר מטבעות לפי שער קבוע להדגמה.'''

rates = {'USD': 1.0, 'ILS': 3.7, 'EUR': 0.92}

usd = amount / rates[from_]

return f'{usd * rates[to]:.2f} {to}'

if __name__ == '__main__':

mcp.run() # stdio

`

זה כל הקסם: docstring הוא ה-description, הטיפוסים הם הסכמה, ו-FastMCP עושה את שאר העבודה. עוד כמה שורות מוסיפות resources (@mcp.resource) ופרומפטים (@mcp.prompt).

צריכה מצד הלקוח

ב-Claude Desktop מוסיפים לקובץ הקונפיגורציה:

`json

{

"mcpServers": {

"currency": {

"command": "python",

"args": ["/abs/path/server.py"]

}

}

}

`

מקוד, לקוח MCP סטנדרטי (SDK או adapters של LangChain/openai-agents) מתחבר, מגלה את רשימת הכלים באופן דינמי (tools/list) וממפה אותם ל-tool definitions שראינו בשיעור הקודם. שים לב: רשימת הכלים משתנה בין שרתים — הקוד שלך חייב להתמודד עם כלים שהופיעו או נעלמו בין גרסאות, לא לקבע את השמות.

האקולוגיה — והזהירות שדרושה

יש אלפי שרתי MCP ציבוריים: GitHub, Postgres, Slack, דפדפן, מערכות קבצים. זה חיסכון אדיר בזמן פיתוח — וגם שטח לתקיפה: אתה מריץ קוד של אנשים זרים ונותן למודל גישה לכלים שלהם. הכללים שלי: (1) שרתים ציבוריים רק ב-container או עם הרשאות מינימליות; (2) כל שרת חדש עובר קריאת קוד של חמש דקות; (3) כלי הרסניים (מחיקה, חיוב) לא נכנסים לסוכן אוטונומי בלי אישור אדם. נרחיב בשיעור האבטחה, אבל תתחיל לחשוב על זה מעכשיו.

פרומפט מוכן להעתקה

שרת MCP מינימלי: ```python from mcp.server.fastmcp import FastMCP mcp = FastMCP('notes') @mcp.tool() def add_note(text: str) -> str: '''שומר פתק לקובץ מקומי.''' with open('notes.txt', 'a') as f: f.write(text + '\n') return 'saved' mcp.run() ```

פרומפט בדיקה ללקוח (אחרי חיבור השרת): ``` קרא לכלי convert עם amount=100, from_=ILS, to=USD, ואז תאר במילה אחת אם התוצאה הגיונית לדעתך. אל תשתמש בכלים אחרים. ```

💪 תרגיל

עטוף API ציבורי שאתה אוהב (Open-Meteo למשל) לשרת MCP עם שני tools: forecast(city, days) ו-compare(city_a, city_b). חבר ל-Claude Desktop או ללקוח קוד, ותעד שיחה שבה המודל בוחר לבד בין שני הכלים.
