נועה · השמע את המרצה

סט זהוב: השלד של כל הערכה

סט זהוב הוא 30–200 מקרים מייצגים של המשימה האמיתית: קלט, פרמטרי מערכת והתוצאה הרצויה — תשובה מדויקת, קריטריונים או דירוג מומחה. מקורות טובים: לוגים פרודקשן (לפני שמוחקים), סימון ידני שלך, שיחות עם משתמשים. חוקי ברזל: (1) הסט נבנה לפני השינוי, לא אחרי — אחרת אתה כותב מבחן שהתשובה שלו ידועה; (2) כולל מקרי קצה ושגיאות — לא רק את מה שקל; (3) הוא גדל בכל פעם שמוצאים באג — כל באג שנתפס בפרודקשן הוא שאלה שחסרה בסט. הסט הוא הזיכרון המוסדי של המערכת שלך.

מדידה אובייקטיבית לפני שופטים

לא הכול צריך LLM-as-judge. אם אפשר למדוד עם קוד — עדיף, כי קוד לא משנה דעה: exact-match ו-f1 לסיווג, הרצת הקוד + assertions לקוד שנוצר, ולידציית JSON לפלט מובנה, בדיקת URL לציטוטים.

`python

def passes(case):

out = agent(case['input'])

assert case['must_include'] in out

if case.get('must_not'):

assert case['must_not'] not in out

return True

`

רק את מה שקוד לא יודע למדוד — 'האם התשובה מועילה' — מוסיפים לשופט. כל אחוז מההערכה שרץ דטרמיניסטית הוא אחוז שלא תצטרך לכייל.

LLM-as-judge: כלים ומלכודות

שופט-LLM טוב צריך: מודל חזק (לא הזול בדל), רובריקה מפורטת (1–5 עם תיאור לכל ציון, לא 'מדוד איכות'), את כל ההקשר הרלוונטי, ופלט מובנה. מלכודות מתועדות: הטיית אורך (תשובה ארוכה נראית טוב יותר — תנרמל), הטיית מיקום (מעדיף את הראשון ב-pairwise — תהפוך סדר ותמצע), והטיית נימוק מוביל. כיול חובה: 15–20 מקרים שאתה מדרג בעצמך, מדידת הסכמה (Cohen's kappa מעל 0.6 בערך), ובדיקת המקרים שבהם אתם חולקים — שם הרובריקה חסרה.

הרצה בכל שינוי: רגרסיה כהרגל

ה-eval לא פרויקט חד-פעמי אלא בדיקת CI: כל שינוי פרומפט, מודל או כלי מריץ את הסט ומדווח דלתא מול baseline — accuracy 0.82 → 0.86 (+4).

`python

results = [run_eval(c) for c in golden]

acc = sum(results) / len(results)

assert acc >= BASELINE - 0.02, f'regression: {acc:.2f} < {BASELINE}'

`

שמור היסטוריה (JSON ב-git מספיק): מה השתנה, מה הציון, כמה עלה. וטיפ מהשטח: ריצה על מודל זול לפיתוח יומיומי, וריצה מלאה על המודל היקר לפני release — ככה ה-evals לא הופכים לצוואר בקבוק של הצוות.

פרומפט מוכן להעתקה

שופט מובנה עם רובריקה: ``` אתה מעריך תשובות של סוכן תמיכה. שאלה: {question} תשובה: {answer} דרג 1–5 בשלושה ממדים, 5 = מושלם: - relevant: עונה ישירות על השאלה - accurate: נכון עובדתית לפי {reference} - concise: בלי מילים מיותרות החזר JSON: {"relevant": n, "accurate": n, "concise": n, "reason": "..."} ```

בדיקת רגרסיה ב-CI (pytest): ```python def test_no_regression(golden): acc = sum(run(c) for c in golden) / len(golden) assert acc >= 0.85, f'regression to {acc:.2f}' ```
