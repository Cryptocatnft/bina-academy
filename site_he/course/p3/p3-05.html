הפייפליין ונקודות הכישלון שלו

RAG בנוי מחמישה שלבים: ingest (parse לטקסט) → chunk (חיתוך) → embed (וקטורים) → retrieve (חיפוש top-k) → generate (תשובה עם ציטוטים). התשובה הגרועה של המודל היא בתשעים אחוז מהמקרים לא אשמת המודל — הוא פשוט לא קיבל את הקטע הנכון. הכלל המנחה: שפר את השליפה לפני שאתה נוגע בפרומפט. כל שקל שאתה משקיע בפרומפט של הגנרטור שווה שקל; כל שקל בשליפה שווה עשרת. עכשיו בוא נדבר על מה שבאמת קובע.

חיתוך: chunking בלי לערוף

ברירת מחדל: חלון קבוע של 500–1000 טוקנים עם overlap של 10–20%. זה פוגע בשתי חזיתות: קטע גדול מדי מדלל את הסיגנל באמבדינג, קטע קטן מדי מאבד הקשר. שדרוגים שמשתלמים: חיתוך לפי מבנה (כותרות markdown, תאי טבלה), חיתוך סמנטי לפי משפטים, ו-late chunking שמחשב אמבדינג לפסקה עם הקשר המסמך. שמור metadata (שם קובץ, כותרת, מספר קטע) — בלי זה אין ציטוטים ואין דיבוג.

`python

from langchain_text_splitters import MarkdownHeaderTextSplitter

splitter = MarkdownHeaderTextSplitter(['#', '##', '###'])

chunks = splitter.split_text(doc)

`

אמבדינגים וחיפוש וקטורי

אמבדינג הופך טקסט לוקטור; קרבה סמנטית = קרבה גיאומטרית (cosine). מודלים נפוצים: text-embedding-3, Cohere embed, BGE. טעויות מתחילים: לערבב מודלי אמבדינג בין יצירה לשאילתה (חובה זהה), לא לנרמל וקטורים, לשכוח ששאילתה קצרה ('מה המחיר?') זקוקה לשכתוב — תבנית שאילתה שהופכת אותה לפסקת תשובה משוערת. עברית עובדת טוב במודלים המובילים, אבל תמיד תבדוק על הנתונים שלך, לא על הבלוג של מישהו.

`python

q = client.embeddings.create(model='text-embedding-3-small', input=query).data[0].embedding

hits = index.search(np.array(q), k=8)

`

היברידי + רי-ראנקינג: השדרוג הגדול

חיפוש וקטורי מפספס שמות מדויקים, קודי שגיאה ומונחים טכניים — שם BM25 מנצח. חיפוש היברידי מריץ את שניהם וממזג דירוגים (RRF — Reciprocal Rank Fusion):

`python

def rrf(list_a, list_b, k=60):

scores = {}

for lst in (list_a, list_b):

for i, doc in enumerate(lst):

scores[doc] = scores.get(doc, 0) + 1 / (k + i + 1)

return sorted(scores, key=scores.get, reverse=True)

`

ואז reranker צולב (Cohere Rerank, BGE-reranker) מדרג מחדש את 50 המועמדים ומחזיר top-3 איכותיים בהרבה. זה הכפתור שמרים את ה-RAG שלך מ'סביר' ל'טוב'.

פרומפט מוכן להעתקה

פרומפט תשובה מבוסס-קטעים: ``` ענה רק על סמך הקטעים שסופקו. צטט מזהה קטע בסוף כל טענה כמו [3]. אם הקטעים לא מכילים את התשובה — כתוב בדיוק: 'לא מצאתי במסמכים'. אל תשלים מידע מהידע הכללי שלך. ```

שאילתה משודרגת לפני שליפה: ``` שכתב את שאלת המשתמש כפסקת חיפוש עצמאית בת 2–3 משפטים, כולל מונחים נרדפים וקודי מוצר רלוונטיים. החזר רק את הפסקה. ```
