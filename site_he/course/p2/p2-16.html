המפרט: מה חייב להיות

האסיסטנט חייב לכלול — זה גם דף הבדיקות של הגמר:

1. שלושה כלים אמיתיים לפחות — למשל: ניהול משימות (קובץ/מסד), חיפוש ברשת, חיפוש במסמכים שלכם (RAG מיני).

2. זיכרון מתמשך — עובדות עליכם ועל העדפותיכם נשמרות בין שיחות (קובץ, SQLite או מסד וקטורי).

3. זרימת LangGraph — לא צ'אט אחד גדול אלא החלטות: איזה כלי, מתי לזכור, מתי לוותר.

4. Evals — 10 משימות מדידות: "זכור שאני מעדיף בוקר", "הוסף משימה ותזכיר לי מחר".

5. פריסה — Docker, ענן, לינק ציבורי.

מי שרוצה ציון מצטיין: חברו לפחות כלי אחד דרך MCP.

זיכרון: ההבדל בין כלי לעוזר

אסיסטנט בלי זיכרון הוא זר מוכשר שפוגשים כל פעם מחדש. שלוש רמות לממש, מהקל לקשה:

`python

import json, pathlib

MEMORY = pathlib.Path("memory.json")

def remember(fact: str):

data = json.loads(MEMORY.read_text()) if MEMORY.exists() else {}

data["facts"].append(fact)

MEMORY.write_text(json.dumps(data))

`

רמה 1: עובדות גולמיות ("קוראים לי דנה, מעדיפה תשובות קצרות"). רמה 2: סיכום שיחות שנשמר ומוזרק לכל שיחה חדשה. רמה 3: אמבדינגים — לשלוף זיכרונות רלוונטיים לפי השאלה הנוכחית. כל שלוש הרמות הן פחות מחמישים שורות קוד, והן מה שגורם למשתמש להרגיש שמישהו *מכיר* אותו.

בחירת כלים: אישיות זו אסטרטגיה

הכלים שתבחרו יגדירו את האסיסטנט — ואת הסיפור שלכם בראיון. "כלי לניהול משימות" זה בסדר; "אסיסטנט של מחפשי עבודה שקורא מודעות דרך RSS, מדרג לפי פרופיל שמסוכם בזיכרון, ומנסח מייל פנייה" — זה כבר פרויקט שמראיינים רוצים לדבר עליו עוד עשרים דקות. בחרו כלים שפותרים כאב אמיתי שלכם, כי תצטרכו להריץ אותו באמת שבועות. אסיסטנט שמשתמשים בו — עם לוגים שמוכיחים את זה — שווה עשרה מעולים שאיש לא הפעיל.
