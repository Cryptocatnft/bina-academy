אתר התיק: עמוד אחד, חמישה פרויקטים

עמוד אחד מספיק — ראיונות מבלים 90 שניות, אז תעצבו לסקירה. מבנה:

  • כותרת: שם, תואר יעד, שורת מיצוב אחת, לינקים (לינקדאין, GitHub, מייל).
  • פרויקטים — לכל אחד פיץ' של שתי שורות, צילום מסך או GIF קצר, ושלושה לינקים: דמו חי, קוד מקור, README. לפי חוזק, הטוב ראשון.
  • אודות: 3 משפטים, אנושיים, עם מסלול הלימוד ומספר האימות של התעודה ברגע שיהיה לכם (שיעור 24).

בנו איפה שהכי מהיר ב-2026 — GitHub Pages, Carrd, אתר Notion או בונה אתרים AI; הפלטפורמה לא רלוונטית, ה*לינקים העובדים* הם הכול. בדקו כל לינק בטלפון. לינק דמו מת נקרא פרויקט מת.

GitHub ללא-מתכנתים

גם עם פרויקטים בלי קוד, GitHub הוא המקום שמעריכים טכניים מסתכלים בו — הוא מסמן שאתם דוברים את התרבות שלהם. ה-GitHub המינימלי-הכרחי:

1. שם אמיתי או מזהה עקבי, תמונה, ביו עם תואר היעד ('בונה אייג'נטי AI — n8n, Zapier, LLMs').

2. ריפו אחד לכל פרויקט — גם אם ה'קוד' הוא בעיקר ייצואי JSON, פרומפטים ו-README-ים. זה לגיטימי: הפרומפטים, הסכמות ויומני הבדיקות שלכם *הם* הארטיפקטים.

3. README רציני לכל ריפו: מה זה עושה, ארכיטקטורה, צילומי מסך, החלטות עיצוב, תוצאות בדיקות, מגבלות. נעצו את הריפואים הטובים.

4. ריבועים ירוקים עוזרים אבל לא חובה — חמישה ריפואים מוצקים עם README-ים מעולים מנצחים שנה של רעש commit.

אימון ה-take-home משיעור 23 ירגיש מוכר אם יבקשו ריפו — הרבה עושים. אתם בונים את השריר הזה עכשיו.

רקמת החיבור

אמינות מצטברת כשהכול מקושר. צ'קליסט:

  • זהות עקבית: אותו שם, אותה תמונה, אותו תואר בלינקדאין, GitHub והאתר — מנועי חיפוש וראיונות שניהם מתגמלים קוהרנטיות.
  • לינקים בכל מקום: Featured בלינקדאין ← האתר והריפואים; האתר ← לינקדאין; כל README ← הדמו; סעיף הפרויקטים בקורות ← הכול.
  • צילומי מסך עובדים: תמונות שנטענות מהר ומראות את *הדבר עובד*, לא דיאגרמות מופשטות.
  • חפשו את עצמכם בגוגל (מצב גלישה בסתר): מה באמת מופיע? תקנו את חמש התוצאות הראשונות שבשליטתכם.

בונוס: מייל מקצועי על דומיין משלכם אם יש — name@yourdomain מנצח name1234 בכלכלת האמון של 2026, וזו עבודה של 10 דקות.

נוכחות כהרגל

האתר הוא ארטיפקט חי, לא מטלה חד-פעמית. החזיקו יומן בנייה — כל פרויקט חדש, אבן דרך בקורס או אוטומציה מעניינת מקבלים רשומה קצרה (משתלב מושלם עם הצינור משיעור 15, שיכול לנסח אותן). עדכנו את האתר חודשית: החליפו לפרויקט החדש ביותר, רעננו מספרים בתוצאות ('12 אייג'נטים שוחררו', 'מיון מהיר ב-40%'). ראיות ציבוריות קטנות ועקביות מנצחות ברק ספורדי — חצי שנה של יומן בנייה גלוי זה שיא, ושיא הוא האובייקט המשכנע ביותר בשוק של 2026, כי הוא הדבר היחיד שאי אפשר לזייף בראיון. בניתם אחד כזה כל הקורס. עכשיו הוא פומבי.
