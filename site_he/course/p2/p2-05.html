למה JSON מנהל את העולם

JSON הוא הפורמט האוניברסלי שבו תוכנה מחליפה דאטה: {"name": "Dana", "score": 8}. כש-AI מחזיר JSON, הוא יכול לזרום ישר לגיליון, למסד נתונים, לאתר או לצעד הבא באוטומציה. ברגע שלפלט יש סכמה, עברתם מ*צ'אט* ל*צינור עיבוד*. כל מוצר AI רציני — מיון פניות תמיכה, העשרת לידים, עיבוד מסמכים — הוא פלט מובנה מתחת למכסה המנוע. אם לומדים כישרון מקצועי אחד מהמודול הזה — שיהיה זה.

אנטומיה של פרומפט סכמה

פרומפט מבני ברמת ייצור מורכב מארבעה חלקים:

1. המשימה במילים פשוטות.

2. הסכמה המדויקת — שמות שדות, טיפוסים, ערכים מותרים. היו קפדנים.

3. כללים לאי-ודאות — מה עושים עם דאטה חסרה (null, "unknown", מערך ריק — בחרו אחד ואכפו אותו).

4. דוגמה אחת — פלט מלא, תקין וממולא.

דוגמה לשדה: "sentiment": אחד מ-"positive" | "negative" | "neutral" | "mixed". תנו למודל אוצר מילים מפורש — והוא יפסיק להמציא כזה משלו. המודל יחקה את צורת הדוגמה שלכם כמעט בשלמות.

וולידציה: תסמכו, אבל תבדקו

גם עם פרומפט מושלם, מודלים מקיאים מדי פעם JSON שבור — פסיק תועה, הערה, גדרות markdown סביב הפלט. הרגל המקצועי: תמיד לאמת. להדביק לבודק JSON, או בקוד להריץ json.loads() ולתפוס שגיאה. כללים הגנתיים בפרומפט: 'החזר JSON גולמי בלבד, בלי markdown, בלי פרשנות, בלי גדרות קוד.' ולתכנן סכמות סלחניות בעיצובן: enums במקום טקסט חופשי, מספרים איפה שאפשר, ומערך "uncertain_fields" — שיהיה למודל לאן הוגן לשים ספק. כשלים צריכים להיות נראים, לא שקטים.

מעבר ל-JSON

אותה משמעת תקפה לפורמטים אחרים: שורות CSV לגיליונות, YAML לקונפיגורציה, SQL שהמודל כותב בשבילכם, ואפילו XML כשמערכת ישנה דורשת. העיקרון קבוע: קודם מחליטים את הצורה, אחר כך מפרומפטים אותה. שימו לב: להרבה API-ים וכלי צ'אט יש היום מצב 'פלט מובנה' או JSON מובנה — תשתמשו בו כשיש, אבל תדעו לעשות את זה ביד, כי ראיונות ומערכות ישנות לא תמיד מגישות לכם את כפתור הקלות.

פרומפט מוכן להעתקה

חלץ דאטה מובנית מהטקסט שלמטה. החזר JSON גולמי בלבד (בלי גדרות markdown, בלי פרשנות) שתואם בדיוק לסכמה: {"company": string, "industry": string, "urgency": "low"|"medium"|"high", "key_points": string[], "next_action": string, "missing_info": string[]} כללים: null לכל דבר שלא צוין. לא לנחש. אם ערך דו-משמעי — שים אותו ב-missing_info. טקסט: [הדביקו טקסט]

תתנהג כמאמת קפדן. הנה הסכמה שלי: [הדביקו סכמה]. הנה פלט שנוצר ב-AI: [הדביקו פלט]. רשום כל שדה שמפר את הסכמה, כל ערך מוזר, והחזר את ה-JSON המתוקן.
