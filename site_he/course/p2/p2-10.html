מעבירים את ה-RAG לאוויר: FastAPI והיכרות עם Docker

🎯 מה תדעו לעשות: להפוך את מנגנון ה-RAG לשירות HTTP חי עם FastAPI, ולעטוף אותו בקונטיינר Docker — כדי שלמעסיק אפשר יהיה ללחוץ על לינק ולראות.
נועה · השמע את המרצה

FastAPI: API בעשרים שורות

`python

from fastapi import FastAPI

from pydantic import BaseModel

app = FastAPI()

class Ask(BaseModel):

question: str

@app.post("/ask")

def ask_endpoint(item: Ask):

answer, sources = rag_answer(item.question)

return {"answer": answer, "sources": sources}

`

הרצה: uvicorn main:app --reload, ויש לכם שירות HTTP חי עם תיעוד אוטומטי ב-/docs — כן, FastAPI בונה לבד דף בדיקות שבו אפשר ללחוץ ולנסות. שימו לב ל-Ask מסוג pydantic — שיעור 7 עובד כאן בשבילכם: קלט לא תקין נדחה אוטומטית עם שגיאה ברורה. ככה נראה קוד שמעסיקים מזהים כמקצועי.

Docker: הקופסה שבה הכול רץ

"אצלי עובד" זו הבדיחה הכי עצובה בפיתוח. Docker פותר: הקוד, הספריות והגדרות הריצה נארזים לקונטיינר שרץ *בכל מקום* בדיוק אותו דבר. קובץ Dockerfile:

`dockerfile

FROM python:3.12-slim

WORKDIR /app

COPY requirements.txt .

RUN pip install --no-cache-dir -r requirements.txt

COPY . .

CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "80"]

`

בנייה והרצה: docker build -t rag-api . ואז docker run -p 8080:80 rag-api. 21% מהמשרות האג'נטיות דורשות Kubernetes — Docker הוא התנאי המקדים שלו. בפריסה לענן כמעט תמיד הקונטיינר הזה הוא מה שמעלים.

פריסה: לינק ציבורי בחינם

את הקונטיינר מעלים לשירות חינמי לפרויקטים קטנים — למשל Render או Railway: מחברים את מאגר ה-GitHub, מצביעים על ה-Dockerfile, והשירות בונה ומריץ לבד, כולל HTTPS. שימו לב: מפתחות API נכנסים כ-environment variables בפאנל של השירות — לא בקוד, לא ב-Git. מהרגע הזה יש לכם https://my-rag.onrender.com/ask שאפשר לשלוח בלינקדאין, בקורות החיים ובכל פנייה למגייס. שירות חינמי נרדם אחרי חוסר פעילות — זה בסדר לתיק עבודות, וראוי לציין ב-README איך מעירים אותו.

לחשוב כמו פרודקשן

שלושה שדרוגים שמפרידים דמו משירות: (1) טיפול בשגיאות — מה קורה כשה-LLM נופל? קוד סטטוס 500 עם הודעה ברורה, לא קריסה. (2) לוגים — כל קריאה נרשמת עם timestamp, שאלה וזמן תגובה. (3) מפתח פשוט — פרמטר X-API-Key שנבדק בmiddleware, כדי שלא יחייבו אתכם על המפתח של OpenAI שלכם. הוסיפו ב-README דוגמת קריאת curl. מעסיק שרואה שחשבתם על זה — כבר מראיינים אתכם על תנאים אחרים.
