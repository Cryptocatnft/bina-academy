Git ו-GitHub לתיק עבודות

🎯 מה תדעו לעשות: לשלוט בזרימת העבודה הבסיסית ב-Git — commit, branch, push — ולהקים פרופיל GitHub שמציג פרויקטים כמו שמעסיקים מצפים לראות.
נועה · השמע את המרצה

המינימום שחייבים: המעגל היומיומי

Git עוקב אחרי שינויים בקוד ומאפשר "תמונות מצב" (commits) שאפשר לחזור אליהן. המעגל שתריצו מאה פעמים בשבוע:

`bash

git init # פרויקט חדש (פעם אחת)

git add . # מוסיף את השינויים ל-staging

git commit -m "add RAG endpoint" # שומר תמונת מצב

git status # מה השתנה

`

הודעת commit טובה אומרת *מה* נעשה ו*למה* — "add RAG endpoint" ולא "עדכונים" או "final FINAL v2". שימו לב: .gitignore קובע מה לא נכנס למאגר — ושם חייבים להיות .env, __pycache__ ו-.venv. מפתח שדולף דרך Git זה הסיוט של כל ג'וניור.

Branches: לנסות בלי לשבור

branch הוא עולם מקביל לניסויים:

`bash

git switch -c feature/rag-search # branch חדש לפיצ'ר

git commit -am "wip: chunking"

git switch main # חזרה ל-stable

git merge feature/rag-search # מיזוג כשעובד

`

עובדים על הפיצ'ר ב-branch, ורק כשהוא עובד ממזגים ל-main. זה גם הבסיס לעבודה בצוות — pull request: מבקשים שמישהו יסתכל על השינוי לפני שנכנס. בפרויקטים שלנו תעבדו ככה בלי לשבור את מה שכבר עובד — וזו בדיוק השפה שתשמעו בכל ראיון: "תפתחו ב-branch ותפתחו PR".

GitHub: מהמחשב שלכם לעולם

`bash

git remote add origin https://github.com/USERNAME/project.git

git push -u origin main

`

מרגע זה הקוד שלכם חי ברשת, עם היסטוריה ותיעוד. שלושה דברים שהופכים מאגר למציג: README — דף פתיחה שמסביר בשלוש שורות מה זה, למה, ואיך מריצים; קומיטים נקיים — היסטוריה שנראית כמו עבודה אמיתית; לינק לדמו חי בראש ה-README. מעסיק שפותח מאגר מחליט ב-30 שניות אם להמשיך לקרוא. מה בדיוק לשים ב-README — שיעור 20 כולו על זה.

ה-GitHub שלכם זה הראיון הראשון

ב-2026 מגייסים בודקים GitHub לפני שיחת הטלפון — זה קורה סטנדרט בסטארטאפים ישראלים ובחברות אמריקאיות. מה שנראה טוב: פרויקטים סיומים ולא ערימת חצאי-תרגילים; README ברור עם צילום מסך של המערכת רצה; קוד קריא שמפחית סודות בתוך .env. מה שנראה רע: מאגר אחד בשם "project" שמכיל הכול, הודעות קומיט כמו "asdf", ומפתחות API בתוך הקוד. המסקנה: כל פרויקט שתסיימו מכאן ואילך — נקי, מתועד, מפורסם.
