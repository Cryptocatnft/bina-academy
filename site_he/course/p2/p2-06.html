🎯 מה תדעו לעשות: לכתוב קוד Python שקורא ל-OpenAI ו-Anthropic SDK, לנהל מפתחות API בבטחה, לשלוט בעלויות ולממש retries.
נועה · השמע את המרצה

הקריאה הראשונה

שתי ה-SDK-ים הנפוצות: OpenAI ו-Anthropic. התקנה: pip install openai anthropic. הקריאה:

`python

from openai import OpenAI

client = OpenAI() # קורא מפתח ממשתנה הסביבה OPENAI_API_KEY

resp = client.chat.completions.create(

model="gpt-4o-mini",

messages=[{"role": "user", "content": "תסכם במשפט: מה זה API"}],

)

print(resp.choices[0].message.content)

`

ב-Anthropic זה כמעט זהה: client.messages.create(model=..., max_tokens=..., messages=[...]). פרמטר temperature שולט ביצירתיות — 0 לעקביות, 0.7 לגיוון. זכרו: כל מודל יש לו שם ומחיר אחר — תמיד תדעו לאיזה מודל אתם קוראים.

מפתחות: אף פעם לא בקוד

מפתח API זה כמו כרטיס אשראי שמאפשר לכל אחד לחייב אתכם. הכלל הראשון: מפתח אף פעם לא נכנס לקוד או ל-Git. שומרים במשתנה סביבה:

`bash

export OPENAI_API_KEY="sk-..." # או בקובץ .env עם הספרייה python-dotenv

`

ומוסיפים את .env ל-.gitignore (ילמד בשיעור 8). אם מפתח דלף ל-GitHub ציבורי — בוטים ימצאו אותו תוך דקות וירוקנו לכם את החשבון. שנה את זה: גם אם עוד לא קרה לכם, זה קרה למישהו שראיינתם איתו.

שליטה בעלויות

מודלים נמדדים ב-$ למיליון טוקנים — קלט ופלט במחירים שונים. מודל מיני זול פי עשרות ממודל דגל. שלושה כללים של מהנדסים: (1) פיתוח על מודל זול, פריסה על חכם — בודקים לוגיקה במיני ומריצים בפרודקשן את המודל שנותן את האיכות. (2) הגבלת פלט — max_tokens חוסך כסף ומונע שיגעונות. (3) מדידה — מודלים כמה טוקנים עברו ביום וכפלו במחיר. קריאה טיפוסית של צ'אט קצר על מודל מיני עולה פחות מאגורלית בודדת — אבל מערכת עם אלף משתמשים זה כבר תקציב.

retries: ה-API תמיד נופל בסוף

רשת נופלת, rate limits נגמרים, שרתים משתעלים — קוד פרודקשן חייב להתמודד:

`python

import time

def call_llm(client, **kw):

for attempt in range(3):

try:

return client.chat.completions.create(**kw)

except Exception as e:

if attempt == 2:

raise

time.sleep(2 ** attempt) # 1s, 2s — backoff אקספוננציאלי

`

backoff אקספוננציאלי — המתנה שמכפילה את עצמה — הוא הסטנדרט. שאלת ראיון קלאסית: "מה קורה כשה-API נופל באמצע batch?" — עכשיו יש לכם תשובה עם קוד.

פרומפט מוכן להעתקה
