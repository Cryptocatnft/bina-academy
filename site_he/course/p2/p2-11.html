מה הופך מערכת לאייג'נט

עם RAG, אנחנו קובעים את הזרימה: שאלה ← שליפה ← תשובה. אייג'נט הופך את ההיגיון: המודל מקבל מטרה ורשימת כלים, ומחליט לבד מה להריץ ומתי — בלולאה:

1. המודל מסתכל על המטרה והכלים.

2. קורא לכלי (function call).

3. מקבל תוצאה, מחליט אם הספיק.

4. חוזר עד סיום או חסימת לולאה.

זו ההבחנה שמגייסים בודקים: להבדיל בין pipeline שמפעילים לבין אייג'נט ש*מחליט*. Multi-agent — כמה אייג'נטים עם תפקידים — מופיע ב-16% מהמשרות, נגיע אליו בשיעור 15.

Function calling: הידיים של האייג'נט

כלי (tool) הוא פונקציה רגילה בקוד שלכם שהמודל יכול לבקש להריץ:

`python

tools = [{

"type": "function",

"function": {

"name": "get_order_status",

"description": "מחזיר סטטוס הזמנה לפי מספר",

"parameters": {"type": "object",

"properties": {"order_id": {"type": "string"}},

"required": ["order_id"]},

},

}]

`

המודל לא מריץ כלום — הוא מחזיר "תריצו את get_order_status עם order_id=123", אתם מריצים בקוד ומחזירים לו את התוצאה להמשך החשיבה. ה-description הוא פרומפט אנג'ינירינג: תיאור מדויק = כלי שנקרא נכון. Tool use מופיע ב-11% מהמשרות — ובפועל, בכל אייג'נט אי פעם.

LangChain ו-LangGraph: הסטאק שנדרש

לא בונים את לולאת האייג'נט ביד — משתמשים בפריימוורק. LangChain (15% מהמשרות) נותן את אבני הבניין: מודלים, כלים, טעינת מסמכים. LangGraph (13%) נותן את השליטה בזרימה: אייג'נט כגרף של צמתים וקשתות, עם state, התערבות של אדם (human-in-the-loop), וניטור. הרעיון המרכזי ב-LangGraph: ה-state עובר בין צמתים, וכל צומת מעדכן אותו ומחליט לאן הגרף ממשיך — ככה בונים זרימות מורכבות בלי ללכת לאיבוד בלולאות מקוננות. בפרויקט 1 (שיעור 13) נבנה על זה אייג'נט תמיכה שלם.

MCP: התקע האוניברסלי

MCP — Model Context Protocol — הוא הסטנדרט של 2026 לחיבור כלים לאייג'נטים: פרוטוקול אחיד שבו שרת MCP חושף כלים (חיפוש, מסדי נתונים, מערכות חברה) וכל לקוח תומך MCP יודע להשתמש בהם — בלי לכתוב אינטגרציה לכל צומת מחדש. 27% מהמשרות האג'נטיות כבר דורשות MCP, ואנתרופיק, אופן-AI וגוגל תומכות בו — זה כמו ש-HTTP היה לאינטרנט. בפועל: כותבים שרת MCP קטן שמגלה את הכלים שלכם (@mcp.tool על פונקציות, סטנדרטי גם ב-Python), ואייג'נטים שונים יכולים לצרוך אותם מיד. מי שמגיע לראיון עם MCP ביד — מגיע מהעתיד.
