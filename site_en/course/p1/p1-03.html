Projects & Memory: An AI That Remembers

🎯 What you'll be able to do: Use Projects to give the AI a permanent home base with your documents, and understand Memory so it stops forgetting what matters.
Alex · Play the lecturer

The forgetting problem

By default, every chat is a clean slate. That's why you keep re-pasting that recipe list, that project brief, that teacher's email. Two features solve it. Projects (in ChatGPT; Claude has Projects too) is a folder with a shared brain: you drop in files — a PDF of your recipes, your lease, your kid's syllabus — and every chat inside that project can read them. Memory is the AI's notepad about *you*: preferences it picks up across conversations ('user has a nut allergy'). One organizes your stuff, the other accumulates your context. You want both, used deliberately.

Setting up your first Project

Create a Project, give it an honest name — 'Family HQ,' 'Renovation,' 'My Business' — and add a short project instruction: 'This is our family command center. Files include the school calendar and the meal rotation. Default to practical, money-saving answers.' Then upload the relevant files. From now on, any chat you start inside the project already has the calendar, the plans, the history. Five chats about the renovation all share one brain, so chat six doesn't ask 'what renovation?' New topic that's big enough? New project. Small topic? Regular chat is fine.

Memory: the notepad about you

Memory works quietly: during chats the model may save facts — 'prefers metric,' 'kids are 7 and 10,' 'runs a dental clinic' — and uses them later. Find it under Settings → Personalization → Memory, where you can view and delete any single entry. My advice: turn it on, check the list monthly, and delete anything stale or wrong, because wrong memories give wrong answers with confidence. Important nuance: Memory lives in the app, not in a specific project — it colors everything. Sensitive family stuff you'd rather not store? Say so in chat, or keep it out of the conversation entirely. Lesson 19 goes deeper.

When NOT to use these

Projects and Memory are power tools, not a lifestyle. One-off questions ('translate this sign') don't need a project. Tossing every PDF you own into one giant project makes every answer slower and muddier — the AI has to fish through clutter. Same with Memory: if you notice answers drifting — old facts sneaking in, weird assumptions — audit the memory list first. The goal is a small number of clean, focused projects that match the actual compartments of your life, and a memory list you'd be comfortable reading out loud. Curate it like a junk drawer you actually clean.

Copy-ready prompt

Project instruction example: 'This is Family HQ. The uploaded files include our school calendar, meal rotation, and weekly schedule. Assume budget-conscious, time-poor parents. Default to short, practical answers. If a question is better answered with a specific file, use it.'

Memory management: 'Remember that we keep a kosher kitchen and the kids' bedtime is 8:30.' / 'Forget what you know about my old job — I switched careers.'

💪 Exercise

Create one Project that matches a real compartment of your life (family, work, or a home project). Write its project instruction, upload 2-3 real files, and start a chat that uses them. Then open Settings → Memory and delete one stale or unwanted entry.
