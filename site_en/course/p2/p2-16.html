The spec

Your assistant does five things, each mapping to a skill from the market index:

1. Natural conversation — a LangGraph agent with a short system persona and a recursion limit.

2. Memory — long-term facts (name, preferences, projects) stored outside the context window: extract with a structured-output step, store in SQLite, inject a compact summary into each session. This is Lesson 3's 'summarize, compress, retrieve' as engineering.

3. Task tools — add/complete/list to-dos and calendar events (function calling).

4. Web answer tool — search + fetch, with sources in every answer.

5. MCP exposure — the task tools also served via an MCP server, so Claude or any MCP client can drive your assistant.

Docker + deploy + evals + README: the full Lesson 13–15 treatment, with a real UI and a memory demo you can show in 30 seconds.

Memory and context engineering

Memory is where beginners show and engineers shine. Design:

`python

class Memory(BaseModel):

facts: list[Fact] # {key, value, confidence, updated_at}

async def remember(state: AgentState) -> AgentState:

extracted = await extract_facts(state.messages) # structured output

upsert(db, extracted) # SQLite

state.system_extra = compact_summary(db) # ≤150 tokens

return state

`

Run remember at session end, inject the compact summary at session start. Two rules keep it sane: memory is extracted, not raw (store 'prefers short answers', not the whole chat) and bounded (a summary under 150 tokens, or you've rebuilt the context-window problem). 'How would you add memory to an agent?' is a standard interview question — you'll answer with code you shipped.

Prove it works

The capstone eval suite is your certificate's technical core:

  • Memory tests: tell it a fact in session 1, assert it's recalled in session 2 (5 scripted cases).
  • Tool tests: unit-test each tool; integration-test the routing ('remind me tomorrow at 9' → calendar tool, not chat).
  • Web-answer faithfulness: 10 questions scored by your LLM-as-judge for source-grounding.
  • Safety: one test where the user asks for a destructive action and the agent confirms first.

All in CI, results in the README, with a demo script that walks a viewer through conversation → memory recall → tool use → MCP connection in under three minutes. Record that walkthrough as your demo video. Practice it until smooth; in Module 6 you'll perform a version of it live.
