The 20% of Python that does 80% of AI work

Real AI code is mostly data plumbing: fetch a request, reshape some JSON, call a model, return a result. The core toolkit:

`python

user = {"name": "Dana", "tier": "pro", "messages": 3}

tiers = ["free", "pro", "enterprise"]

if user["tier"] not in tiers:

raise ValueError(f"unknown tier: {user['tier']}")

for i, t in enumerate(tiers):

print(i, t)

`

Dictionaries and lists carry nearly all data. if/else, for loops, and try/except control the flow. F-strings build every message and log line. Functions package logic for reuse. Master these five things and you can read most production AI code today.

Functions, errors, and defensive habits

Everything you ship in this course lives inside functions, and every function that touches the outside world needs error handling:

`python

def extract_topic(text: str, max_words: int = 5) -> str:

"""Return a short topic label for a support message."""

if not text.strip():

raise ValueError("empty message")

words = text.strip().split()

return " ".join(words[:max_words]).lower()

`

Note the habits: type hints, a docstring, validation at the top, small pure logic. When an LLM writes code for you in later lessons, *these are the standards you review it against*. Defensive code isn't style — it's what survives contact with real users, and reviewers can smell the difference.

The ecosystem: pip, venv, and reading code

Python's superpower is its packages. pip install requests and you're talking HTTP; pip install pydantic and you have schemas; later, pip install openai langchain chromadb and you're building agents. Two rules: always work inside a virtual environment (python -m venv .venv then activate it) so projects don't poison each other, and pin your dependencies in requirements.txt. Learn to *read* package code on GitHub — being able to open a library's source and find what a function really does is a genuine job skill, and it's how you'll debug agent frameworks in Module 3.

Your first AI-shaped script

Here's the shape of almost every AI script you'll write this course:

`python

import json

def build_prompt(question: str, docs: list[str]) -> str:

context = "\n".join(f"[{i+1}] {d}" for i, d in enumerate(docs))

return f"Answer using only these sources:\n{context}\n\nQuestion: {question}"

if __name__ == "__main__":

docs = ["Refunds take 5 business days.", "VIP users skip the queue."]

print(json.dumps({"prompt": build_prompt("How long is a refund?", docs)}))

`

Build data in, model call in the middle (Lesson 6), structured data out (Lesson 7). That's the whole profession in one pattern. You'll grow this exact file into your first deployed project.
