What MCP actually solves

MCP is an open protocol separating 'who provides capabilities' (an MCP server) from 'who consumes them' (a client — Claude Desktop, your IDE, your agent). A server exposes three types: tools (actions the model runs), resources (readable data — files, DB rows), prompts (ready-made templates). Transport is stdio or HTTP, messages are JSON-RPC. The big win: write a GitHub integration once and every client in the world can use it — and in reverse, you get thousands of ready servers for free.

A first MCP server in ten minutes

`python

from mcp.server.fastmcp import FastMCP

mcp = FastMCP('currency')

@mcp.tool()

def convert(amount: float, from_: str, to: str) -> str:

'''Converts currencies at a fixed demo rate.'''

rates = {'USD': 1.0, 'ILS': 3.7, 'EUR': 0.92}

usd = amount / rates[from_]

return f'{usd * rates[to]:.2f} {to}'

if __name__ == '__main__':

mcp.run() # stdio

`

That's the whole trick: the docstring is the description, type hints are the schema, and FastMCP does the rest. A few more lines add resources (@mcp.resource) and prompts (@mcp.prompt).

Consuming from the client side

In Claude Desktop you add to the config file:

`json

{

"mcpServers": {

"currency": {

"command": "python",

"args": ["/abs/path/server.py"]

}

}

}

`

From code, a standard MCP client (the SDK or adapters from LangChain/openai-agents) connects, discovers the tool list dynamically (tools/list), and maps it onto the tool definitions from the previous lesson. Note: tool lists change between servers — your code must handle tools appearing or disappearing between versions, not hard-code names.

The ecosystem — and the caution it deserves

There are thousands of public MCP servers: GitHub, Postgres, Slack, browsers, file systems. A huge development-time saving — and attack surface: you run strangers' code and give the model access to their tools. My rules: (1) public servers only in a container or with minimal permissions; (2) every new server gets a five-minute code read; (3) destructive tools (delete, charge) don't enter an autonomous agent without human approval. We'll expand in the security lesson, but start thinking about it now.

Copy-ready prompt

Minimal MCP server: ```python from mcp.server.fastmcp import FastMCP mcp = FastMCP('notes') @mcp.tool() def add_note(text: str) -> str: '''Saves a note to a local file.''' with open('notes.txt', 'a') as f: f.write(text + '\n') return 'saved' mcp.run() ```

Test prompt for the client (after connecting the server): ``` Call the convert tool with amount=100, from_=ILS, to=USD, then describe in one word whether the result seems reasonable. Do not use any other tools. ```
